# 시간대별 정원 자동 마감 (Apps Script)

구글 폼 → 스프레드시트로 응답이 쌓이는 **기존 방식을 그대로 두고**, 시간대별 정원(기본 10명)이
차면 폼에서 해당 시간대를 자동으로 없애고 초과 접수를 자동 취소 처리합니다.

## 어디까지 자동으로 막히나

| 상황 | 동작 |
|---|---|
| 10명이 찬 뒤 폼을 **새로 여는** 사람 | 해당 시간대가 선택지에서 **사라짐** → 선택 불가 |
| 웹페이지에서 예약 버튼을 누르는 사람 | 잔여 인원 재확인 후 **마감이면 폼이 열리지 않음** |
| 폼을 **미리 열어두고** 나중에 제출하는 사람 | 제출은 되지만 **자동으로 "정원초과 자동취소" 표시** + 행이 붉게 표시 + 담당자 메일 알림 |
| 동시에 여러 명이 제출 | `LockService`로 순차 처리 → 정원 초과분만 취소 처리 |
| 전 시간대 마감 | **폼 자체가 닫힘** (마감 안내 문구 표시) |

> **한계**: 구글 폼에는 선택지별 정원 기능이 없어서, "제출 자체를 100% 사전에 차단"하는 것은
> 불가능합니다. 폼을 열어둔 채 대기하던 사람은 제출이 들어옵니다.
> 그래서 **선택지 제거(사전 차단) + 제출 후 자동 취소(사후 보정)** 두 겹으로 처리합니다.
> 사후 취소된 분께는 담당자가 안내해 주셔야 합니다.
>
> 사전 차단을 더 확실히 하려면 폼의 날짜·시간을 **한 문항으로 합치는 것**을 권장합니다.
> (예: `5월 31일 (일) 11:00` 하나의 드롭다운) 지금처럼 날짜·시간이 따로면
> "모든 날짜에서 마감된 시간"만 선택지에서 뺄 수 있습니다.

## 설치

1. 응답이 쌓이는 **스프레드시트**를 열고 `확장 프로그램 → Apps Script`
2. 새 스크립트 파일을 만들고 `slot-capacity.gs` 내용을 그대로 붙여넣기
3. 파일 맨 위 `CONFIG` 를 실제 폼에 맞게 수정
   - `CAPACITY` — 시간대당 정원 (기본 10)
   - `COL_DATE` / `COL_TIME` — 스프레드시트 **1행 헤더**(= 폼 질문 제목)에 들어 있는 글자.
     부분 일치로 찾으므로 `날짜`, `시간` 정도면 됩니다.
   - `DATES` — 폼의 날짜 선택지와 **글자까지 똑같이**
   - `NOTIFY_EMAIL` — 정원 초과 접수 발생 시 알림 받을 주소 (선택)
4. 함수 목록에서 **`setupTriggers`** 를 선택하고 실행 → 권한 승인
   - 폼 제출 트리거 + 5분 주기 동기화 트리거가 설치됩니다
5. **`debugAvailability`** 를 실행해 로그에서 슬롯 수·마감 목록이 맞는지 확인

## 웹페이지 잔여 현황과 연결

`index.html` / `index_en.html` 은 `API_URL`(웹 앱)에서 아래 형태를 기대합니다.

```json
{ "slots": [ { "date": "5월 31일 (일)", "time": "11:00", "capacity": 10, "remain": 4 } ],
  "sheetStock": [ { "key": "01 수봉산", "remain": 5 } ] }
```

이미 `doGet` 이 있다면 그 안에서 `slots` 값만 `getSlotAvailability()` 결과로 바꾸면 됩니다.

```js
function doGet() {
  const payload = {
    slots: getSlotAvailability(),   // ← 이 줄만 교체
    sheetStock: getSheetStock()     // 기존 도안 재고 로직 그대로
  };
  return ContentService.createTextOutput(JSON.stringify(payload))
                       .setMimeType(ContentService.MimeType.JSON);
}
```

코드를 고친 뒤에는 반드시 `배포 → 배포 관리 → 편집 → 버전: 새 버전 → 배포`
로 **재배포**해야 웹페이지에 반영됩니다. (배포 URL은 그대로 유지됩니다.)

## 점검

- `debugAvailability` — 전체/마감 슬롯 수를 로그로 출력
- `syncFormChoices` — 폼 선택지를 지금 즉시 동기화
- 스프레드시트에서 취소 처리하려면 `처리상태` 칸에 `취소` 또는 `노쇼` 입력 →
  해당 자리는 다시 예약 가능 상태로 돌아옵니다
