## 1. 사람이 직접 해야 하는 것 (코드로 자동화 불가)

행사 전에 아래 4가지를 반드시 끝내야 합니다.

### ① Apps Script 에 `Code.gs` 추가하고 **새 버전으로 배포**

1. 예약 응답 스프레드시트 → **확장 프로그램 → Apps Script**
2. 파일 추가 → 이름 `Code`, `apps-script/Code.gs` 내용을 통째로 붙여넣기
   - 기존 `slot-capacity.gs` 는 **그대로 둡니다.** `Code.gs` 가 그 함수들을 재사용합니다.
   - 기존에 `doGet` 이 다른 파일에 있었다면 **그 `doGet` 만 지우세요.** (중복 정의 시 오류)
3. 편집기에서 `setupFieldSheets` 를 1회 실행 → `판매` `체크인` `관찰메모` `재고` 탭이 생깁니다
4. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**

> ⚠ **4번을 빼먹으면 편집기에서는 되는데 실서비스만 안 되는 착시**가 생깁니다.
> 코드를 고칠 때마다 매번 새 버전으로 배포해야 합니다.

### ⑤ 스티커 증정 이벤트 확인

유료 구매·체험 후 설문을 마치면 완료 화면에 `HM-0000` 증정 코드가 뜨고,
운영자가 그 코드를 `staff.html` 판매 탭에서 확인하면 스티커 1개가 나갑니다.

운영 방침은 아래와 같이 **확정**되었습니다.

- **증정 스티커는 판매용 스티커 100개와 같은 재고에서 나갑니다.**
  증정한 만큼 판매 가능 수량이 줄어듭니다. 예를 들어 20개를 증정하면 판매 가능 수량은 80개입니다.
  `report.html` 의 스티커 판매 달성률(목표 100개)도 그만큼 상한이 내려가니, 결과보고서를 쓰실 때
  **판매 수량과 증정 수량을 함께 적으시면** 숫자가 설명됩니다. 두 값 모두 리포트에 따로 나옵니다.
- 집계는 분리됩니다 — `스티커`(판매)와 `스티커 증정`이 따로 잡히고, 매출에는 증정이 안 들어갑니다.
- **증정은 유료 구매자에게만 드립니다.** 무료 컬러링 설문에는 증정 코드가 뜨지 않습니다.
  (무료 참가자의 혜택은 SNS 후기 액자입니다.)
- 방침이 바뀌면 `Code.gs` 의 `GIFT_SURVEYS` 한 줄만 고치면 됩니다.

6. 스프레드시트에서 **테스트로 만든 행을 삭제**하고, `재고` 탭의 `차감` 을 0 으로 되돌리기

## 4. 운영 중 알아둘 것

- **회차 선택을 맞춰두면** 무료 체험자의 유료 전환율이 자동으로 계산됩니다.
  결제 화면의 *구매자 연결* 에서 이름을 고르면 1:1로 잡히고, 안 골라도 이름만으로 다시 맞춰봅니다.
- **직전 취소**는 행을 지우지 않고 `취소여부` 칸에 `취소` 를 남기고 재고를 되돌립니다.
  정산 대사 때 "왜 비었는지"를 설명할 수 있고, 운영자 2명이 동시에 기록해도 엉뚱한 행이 지워지지 않습니다.
- **전송 실패**해도 화면은 그대로 진행됩니다. 실패한 기록은 휴대폰에 쌓아뒀다가 네트워크가
  돌아오면 자동으로 보냅니다. 상단에 `전송 대기 N건` 이 보이면 **그 폰을 닫지 마세요.**
- **재고 보정**은 실물과 어긋날 때만 쓰세요. 입력한 숫자가 `잔여` 가 되도록 보정값이 자동 계산됩니다.

## 6. API

읽기는 순수 JSON, 쓰기는 **GET + JSONP** 입니다.
GitHub Pages 에서 Apps Script 로 `fetch()` POST 를 하면 CORS 로 막히기 때문입니다.

| action | 파라미터 | 하는 일 |
|---|---|---|
| `slots` (기본) | – | 기존 응답 형태 그대로 (`slots` `sheetStock` `goods` `surveyProgress`) |
| `report` | – | 결과보고서 항목별 집계 |
| `roster` | `slot` | 회차별 예약자 명단 + 체크인 상태 |
| `sale` | `item` `co` `pay` `slot` `k` / `undo=1` | 판매 기록, 재고 차감 · 직전 취소 |
| `checkin` | `slot` `name` `status` `design` `done` `k` | 참석 · 노쇼 · 도안 |
| `memo` | `tag` `slot` `note` `k` | 관찰 태그 |
| `stock` | `item` `val` `k` | 재고 보정 |
| `survey` | `t` `sid` `i` `n` `d` `slot` `name` `code` | 설문 1건 저장 (조각 전송) |
| `gift` | `code` `k` | 설문 증정 코드 확인 → 스티커 1개 차감 |

> ⚠ 수량 파라미터는 **`co`** 입니다. **`c` 는 구글 인프라 예약어**라서 `?c=` 를 붙이면
> 스크립트에 도달하기 전에 **HTTP 400** 이 납니다.

`cb`(또는 `callback`) 파라미터를 붙이면 `cb({...});` 형태의 JavaScript 로 응답합니다.
